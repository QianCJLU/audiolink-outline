# audiolink outline

用于 VRChat PC 角色的 AudioLink 音乐响应轮廓工具。

## 版本

| 版本 | 游戏内控制 | 同步参数 |
|---|---|---|
| [完整版 0.2.1](https://github.com/QianCJLU/audiolink-outline/releases/tag/v0.2.1) | 属性轮盘、四向偏移、开关与模式 | 66 bits |
| [轻量版 0.1.1](https://github.com/QianCJLU/audiolink-outline/releases/tag/v0.1.1) | 总开关、固定呼吸、自动音频响应 | 2 bits |

轻量版的亮度、色相、轮廓宽度、波峰幅度、呼吸波长、呼吸频率和偏移在 Unity 检查器中设置，构建时写入材质。检查器按安装与目标、颜色与亮度、轮廓宽度、呼吸波形、剪影偏移、构建与兼容分组，每次展开一组；网格列表支持搜索和限高滚动。

全功能版在 Unity 检查器中设置亮度、色相、基础宽度、波峰幅度、呼吸波长和频率的可调范围。游戏内轮盘 0% 对应设定下限，100% 对应上限；水平和垂直偏移分别设置负向、正向极限，居中与归中为零。上下限使用标准效果范围的百分比表示，范围相等时该项为固定值。检查器按六个折叠组组织，目标列表可搜索和滚动。同步占用为 66 bits。

## 实现功能

- 自动音频响应与手动呼吸波动两种模式。
- 轮廓亮度、色相、基础宽度和波峰宽度调节。
- 四向偏移与偏移归中。
- 呼吸波长与频率调节。
- 透明贴图与 lilToon Alpha Mask 支持。
- 目标网格选择、面数预算，以及可折叠、可滚动的网格列表。

## 实现方法

通过 Modular Avatar 合并菜单、参数和动画控制器，使用 NDMF 在角色构建时生成蒙皮轮廓外壳与透明遮罩。着色器负责轮廓外扩、音频响应、呼吸波形、色相和光照计算。

四向轮盘使用本地输入参数，水平和垂直两个浮点参数负责偏移同步。工具共使用 **66 bits** 同步参数。

亮度为 0 时使用场景主灯与光照探针，并读取对应 lilToon 材质的亮度上下限、光照去色和无光照比例。

轮廓与遮罩的三角面数合计受预算限制，默认 **70,000**，可设置范围为 **1,000～200,000**。

## 安装方法

1. 准备 Unity 2022.3、VRChat Avatars SDK、Modular Avatar 1.11+ 和 NDMF 1.11+。lilToon 材质需要安装 lilToon。
2. 从上方对应版本的 Release 下载 `.unitypackage` 并导入项目。
3. 将对应版本的预制件拖入带有 VRC Avatar Descriptor 的角色根对象下：完整版为 `Assets/audiolink outline/audiolink outline.prefab`，轻量版为 `Assets/audiolink outline lite/audiolink outline lite.prefab`。同一角色使用其中一种配置。
4. 在预制件检查器中展开“勾选生成目标”，选择需要轮廓的网格，并设置面数预算。
5. 通过预制件上的 **MA Menu Installer** 选择菜单安装位置。
6. 构建预览或上传角色时生成轮廓。

适用于 PC 角色的 SkinnedMeshRenderer。具有常规主纹理属性的其他材质可使用通用适配；特殊溶解、折射、几何扩展等效果不在适配范围内。

## 完整版使用方法

先在 Unity 检查器设置各项范围，再构建角色。游戏内轮盘数值按编辑器范围映射；以下数值说明使用默认范围。

- **开启描边**：控制轮廓显示。
- **描边属性**：调节亮度、色相、基础宽度、波峰宽度，并选择自动音频响应或手动呼吸模式。两种模式互斥，默认自动音频响应：房间提供 AudioLink 时响应音频，没有 AudioLink 时使用呼吸波动；AudioLink 静音不触发呼吸。
- **呼吸波长**：50% 时波带覆盖约角色高度的四分之一，100% 时约为二分之一。
- **呼吸频率**：50% 时周期为 4 秒，100% 时周期为 2 秒，0% 时停止传播。
- **剪影偏移**：通过四向轮盘移动轮廓，100% 时最大偏移约为角色高度的 5%。
- **偏移归中**：将轮廓偏移设为零。

## 轻量版使用方法

在 Unity 检查器中选择默认开关、默认模式、目标网格及外观属性。属性按分组展开，可恢复分组默认值，偏移可归中。通过 MA Menu Installer 设置菜单安装位置，构建预览或上传角色时应用设置。

游戏内菜单提供开启描边、固定呼吸、自动音频响应。固定呼吸始终播放呼吸波动；自动音频响应在 AudioLink 可用时响应音频，不可用时播放呼吸波动，音乐静音不触发模式切换。

## 效果快照

两版检查器顶部的“效果快照”按钮打开预览窗口，使用当前 Scene 视角或指定场景摄像头与场景灯光，展示未响应的基础轮廓、当前模式的最大波峰，以及固定时刻的颜色与亮度。窗口支持刷新、对准角色和保存 PNG。全功能版可选择游戏默认值、范围下限或范围上限，轻量版使用当前编辑器设置。

快照在独立角色副本上构建，强制显示轮廓，不改动场景角色；不包含其他场景物体的遮挡与相机后处理。
